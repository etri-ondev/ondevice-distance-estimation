# YOLOv5 기반 객체 탐지 및 단안 거리 추정

이 저장소는 객체 탐지와 카메라 기하 기반 단안 거리 추정을 위한 YOLOv5 기반 연구용 구현을 단계적으로 개발하고 공개하기 위한 프로젝트입니다. 구성 요소별 구현과 검토 이력을 이슈와 Pull Request로 관리합니다.

## 문서 작성 상태

실행 환경, 모델 사용법, 실험 매개변수와 관련 논문의 승인된 인용 정보는 구현 통합 과정에서 추가합니다. 논문명·저자·DOI는 승인된 서지정보가 확정된 후 최종 공개 문서에 반영합니다.
